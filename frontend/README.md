# Galerie de maquettes UI/UX — ANELEC TCE

Dossier **isolé** contenant uniquement des maquettes cliquables (5 directions de design × tous les écrans).

- N'importe rien depuis `client/` ni `server/` : l'application en production n'est pas modifiée.
- Données d'exemple uniquement (aucune connexion à la base Supabase).
- Peut être supprimé à tout moment : `rm -rf frontend/`.

Lancement local : `cd frontend && yarn && yarn start` → http://localhost:3000
